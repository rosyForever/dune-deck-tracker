# 沙丘记牌器

[**打开沙丘记牌器**](https://rosyforever.github.io/dune-deck-tracker/)

《沙丘：帝国》实体桌游的个人抽牌堆记牌器。对局中，把已经离开抽牌堆的牌点一下翻面，再打开「抽牌堆」就能看到还可能抽到哪些牌、各有几张。电脑和手机浏览器都能用，牌组会自动保存在当前设备。

## 快速开始

1. **选起始牌组。** 首次打开默认载入《起义》的 10 张起始牌。点右上角「新牌组」可以改用《帝国》本体的 10 张起始牌，或从空牌组开始。选择后会替换当前牌组，误操作可以用「撤销」恢复。
2. **搜索并加牌。** 点底部「添加卡牌」，输入中文或英文牌名。搜索可以同时筛选多个版本，选择《帝国》本体和《起义》后，两者的牌都能加进同一牌组。同名牌每点一次加一张。找不到的牌可以输入名称后添加为自定义牌。
3. **抽到或打出时翻面。** 当一张牌离开实体抽牌堆时，点一下对应卡图，把它从「抽牌堆」中排除。你也可以在打出或展示时补记。已经在抽牌时标记过的那张牌，打出时保持翻面即可。
4. **洗牌或回牌时翻回。** 在「已翻面」里点对应卡图，把那张牌重新计入抽牌堆。如果所有已翻面的牌都已洗回抽牌堆，可以点「全部翻回」。只洗回一部分时，逐张翻回实际洗入的牌。
5. **删牌与撤销。** 某张牌被永久移出牌组或加错时，点卡牌右上角的「−」删除那一张。「撤销」可退回上一次加牌、删牌、翻面或换牌组。

对局中买到的新牌，添加后会立即计入抽牌堆。如果它按规则进入弃牌堆，添加后先把它翻面，等它实际洗入抽牌堆时再翻回。

## 三个视图

| 视图 | 显示内容 |
| --- | --- |
| 全部 | 当前牌组的所有牌。翻面的牌以牌背标记。 |
| 抽牌堆 | 当前未翻面的牌。页面顶部显示剩余总张数。 |
| 已翻面 | 当前在抽牌堆之外的牌。这里仍显示正面卡图，方便辨认和逐张翻回。 |

记牌器按你的手动标记更新，抽牌顺序仍以实体牌堆为准。

「添加卡牌」里的版本选项可以多选。没有选中版本时，搜索范围为整个牌库。

## 在 iPhone 上使用

1. 在 Safari 打开[记牌器网页](https://rosyforever.github.io/dune-deck-tracker/)。
2. 在共享菜单中点「添加到主屏幕」。如果看到「作为网页 App 打开」，可以打开该选项后点「添加」。
3. 以后可以从主屏幕图标直接打开。准备断网使用时，先联网打开一次，待页面和卡图加载后再离线使用。

如果找不到该选项，可参考 [Apple 的 Safari 添加到主屏幕指南](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/27/ios/27)。

### 记录保存在哪里

牌组和撤销记录保存在当前浏览器的站点数据里，刷新或重新打开网页会继续使用上次的牌组。手机和电脑的记录各自保存。清除站点数据会清空该浏览器里的记录。

## 本地运行

这是一个静态网页。电脑上已有 Python 3 时，可以下载或克隆仓库，在仓库目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。网页入口是 `index.html`，记牌界面在 `deck.js`，牌库和卡图在 `library.js`，离线缓存由 `sw.js` 管理。在线版通过 GitHub Pages 从 `main` 分支根目录发布。
